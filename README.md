# r5n-labs Homebrew Tap

Homebrew formulae for r5n-labs projects.

## Installation

```bash
brew tap r5n-labs/tap
```

## Available

### vigil

```bash
brew install r5n-labs/tap/vigil
```

| Platform | Architecture |
|----------|-------------|
| macOS | arm64, x64 |
| Linux | arm64, x64 |

### invoicy

```bash
brew install --cask r5n-labs/tap/invoicy
```

| Platform | Architecture |
|----------|-------------|
| macOS | arm64 |

The signed macOS arm64 installer is also available as a [direct download](https://releases.r5n.dev/invoicy/Invoicy-macos-arm64.dmg).

## Updating

```bash
brew update
brew upgrade
```
